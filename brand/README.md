# Логотип банка-партнёра

Замени файл **`logo.png`** в этой папке (сейчас это прозрачная заглушка 1×1 px) официальным логотипом банка
«Центр-инвест» из материалов кейса (или пресс-кита банка) с тем же именем — лучше горизонтальный, на прозрачном или белом фоне, шириной от 600 px.

Игра подхватит файл сама, без правок кода. Логотип появится:

- на титульном экране — строка «Кейс банка «Центр-инвест»»;
- в холле — на табло над входом в «Финансовую безопасность», на ролл-апе «Неделя стажёра»,
  на банкоматах и на карьерном стенде (стена справа);
- в профиле стажёра, в сертификате и на карточке результата для друзей.

Логотип всегда рисуется на белой плашке, поэтому подойдёт любой цветной вариант.
Нужен SVG или другое имя файла — поменяй путь в `js/brand.js` (`BRAND.logo`).
Нет файла — игра работает как раньше, просто без логотипа.
