# Логотип банка «Центр-инвест»

Здесь два варианта фирменного знака — оба с прозрачным фоном, в фирменном зелёном:

- **`logo.png`** — широкий баннер (знак + «Банк Центр-инвест»): световой короб над окнами операционистов,
  ролл-ап, карьерный стенд, титульный экран, профиль стажёра, сертификат, карточка для друзей;
- **`emblem.png`** — только знак: табло над входом в «Финансовую безопасность», банкоматы, коврик у входа.

Заменить логотип — положи новый файл с тем же именем (лучше PNG с прозрачным фоном, баннер шириной от 1000 px).
Код трогать не нужно. В 3D логотип рисуется на светлой плашке чуть темнее белого, чтобы его не «засвечивало»
эффектом свечения. Убрать логотип — удали файлы: игра работает и без них.
